## 要回答的問題

1. **A 哪裡像 Dashla**:逐項列出 A 的速度表裡讓人聯想到 Dashla 的元素(形狀、圖示位置、數字排法、檔位、配色…)。每項標「Dashla 的特徵 / 很多車都這樣 / 只是巧合」,附來源(Dashla 的 App Store 頁、官網、影片、`07 §3.1`)。
2. **調查**:別的速度表怎麼做,至少涵蓋下面五類,每類 3 個以上的例子。不要重複 `07 §1` 已經查過的;重疊的寫「見 07」。
   - 原廠電動車的儀表或中控車速(例如 Tesla 自己的、Polestar、Rivian、Lucid、Porsche Taycan、BMW iX、Hyundai Ioniq 5、小米 SU7…);
   - 機車 TFT 儀表;
   - 飛機的速度帶(PFD airspeed tape)、抬頭顯示;
   - 自行車碼表、運動手錶、賽車方向盤 / 賽車儀表;
   - 手機的車速 / HUD app(Dashla 以外的),和老車的特別做法(帶狀 ribbon、滾筒 drum 速度表…)。
   每個例子:名稱、它怎麼表示車速(數字 / 刻度 / 帶狀 / 長條…)、怎麼表示超速或警告、怎麼放狀態圖示、值得借的一點、來源 URL + 查詢日期。
3. **原則**:從調查歸納 5–8 條「手機橫放、瞄一眼就懂」的速度表原則,每條附例子。
4. **三個新方向 乙 / 丙 / 丁**:彼此結構不同,和 A 也不同,至少兩個不用圓環。每個方向寫:
   - 名字(兩三個字)和一句話的想法;借了調查裡的哪幾個例子;
   - 中間欄(x 260–584、y 0–390,844 寬)的草圖:ASCII 或標座標的元素清單,visual 要能照著畫;
   - 車速數字的大小和位置、單位、`P R N D`、三個車況圖示、自訂門檻小錶、GPS 提示箭頭各放哪;
   - 下面這些狀態長什麼樣:0、8、72、128 km/h、沒有車速(—)、GPS 備援、車門開著、超過自訂門檻;
   - 為什麼不像 Dashla;
   - 風險:夜間、667、英文、mph、大字、停車畫面會遇到什麼問題,SwiftUI 做起來難不難(一句話就好)。
5. **對照表**:甲(A)/ 乙 / 丙 / 丁 一列一個,欄位:主要形狀、車速多大、瞄一眼先看到什麼、像 Dashla 的程度(高 / 中 / 低)、主要風險。
