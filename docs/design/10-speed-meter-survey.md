## 重點結論

Status: 完成

1. **A 像 Dashla 的是結構,不是顏色**:細圓環 + 深色圓盤框成一塊圓牌、紅色車況燈放進圓牌(Dashla 的特徵);`P R N D` 在上、單位在下、細數字本來不是學 Dashla(L43、L44 早 5 天),被圓牌框起來才變得一樣。A 早就沒有 Dashla 的彩色光暈,還是像,所以只換顏色沒用(§1)。
2. 調查 5 類 24 個例子(只有 Dashla 頁是打開來看的,其他是搜尋摘要):長條、速度帶放在數字**旁邊**;門檻是刻度上的**記號**,超過時改形狀;狀態燈有固定一列;用不到就收起來(§2、§3)。
3. 三個方向都不用圓環:**乙「橫尺」**(數字 + 橫向速度尺 + 最上一列燈)、**丙「直軌」**(數字靠右 + 右邊直立速度軌 + 左邊直欄放檔位和車況)、**丁「大字」**(184 的大數字 + 超過門檻時四角括號 + 下方托盤)(§4)。
4. 像 Dashla:甲高,乙丙丁低。三個都守「照舊」,但都改了 `P R N D` 的位置(L43,老闆定過)和紅色的位置(L87 字面),要老闆和 lead 確認(Q2、Q3)。
5. 不管選哪個,停車畫面都要跟著換(L31,Q4)。ux 推論:乙最接近現在、改動最小;丁數字最大;丙最不像,但 667 和大字最緊。
6. **階段 5 加戊「刻度扇」(§4.4)**:圓的,但只畫上半圈、下半開口;弧上有刻度,會跟著車速填滿,門檻是弧外的小三角;沒有圓盤,檔位、單位、車況都在弧外下方的托盤。§1 #1–#5 都拿掉了,但中間還是圓的輪廓,像 Dashla 的程度「低–中」。

**結論**

- 「像 Dashla」集中在一件事:**用一圈細環 + 深色圓盤,把「檔位 / 數字 / 單位」框成一塊圓牌,再把紅色車況燈放進圓牌裡**(#1、#2、#3,加上 #4)。
- #5、#6、#7 本來不是學 Dashla,但被圓牌框起來以後,排法就和 Dashla 的截圖一樣。拿掉圓牌,它們就回到「一般數位儀表」。
- #14 證明 A 像的是**結構**,不是顏色:A 已經沒有 Dashla 的光暈,車主還是覺得像。所以只換顏色、字型、線粗沒有用,要換結構(brief 目標 3 也這樣要求)。
- 雙翼面板(#10)和左下電量(#11)也會讓整個畫面像 Dashla,這一輪不換,列在待確認 Q7。
