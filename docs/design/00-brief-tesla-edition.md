# 第二十九輪(2026-11-15):車況圖示只在出事時出現

基準 = 現在的頁面 `b98f79f0`(發佈第 8 版)。動手前的頁面、157 張 PNG、`export.sh` 已備份在 `frames/atelier-tesla-edition/stage12/`。**位置一個都不動**,只改「什麼時候畫」和右欄胎壓不足的顏色。

## 車主說的

車主:「這些 icon 只有當有事件時才顯示,平時是不會顯示的。例如前車廂沒關,前車廂的警示才會顯示;胎壓不足,對應的才會顯示。」lead 跟車主問了兩輪(都答「可以」),結果:

1. 開著 = 紅色(照舊);胎壓不足 = 琥珀色(照舊);**關好、正常 = 什麼都不畫**(不畫圓底、不畫淡圖示)。
2. 不知道(車子沒回報或資料太舊):前車廂、車門、後車廂畫灰色虛線(照舊)。**胎壓讀不到:圓裡不畫**,右欄四個「—」(照舊)。
3. 沒連上車 / 車速用 GPS:圓裡一個都不畫(app 照舊,頁面沒有這個狀態,不用新畫)。
4. 位置固定,不往空位補;出現、消失都立刻;開車、停車同一個規則。
5. 車門只有一個圖示,任何一扇開著都亮它,不分哪一扇(舊問題「要不要看得出哪一扇門」車主答了:不用)。
6. 右欄胎壓的數字照常一直顯示;**胎壓不足的那顆改成琥珀色**(輪胎的填色和那個讀數,原本是紅色)。紅色只留給「開著」。
7. 平常圓裡只剩數字、單位、檔位、刻度;圓、刻度、位置都不動,**不加別的東西去填空位**(上一輪「下半圈空著可不可以」這題因此不用再問)。
8. 「以後有資料時」也照這個規則:駐車只在拉起來時出現、車道只在開著時出現;**速限牌只要知道這條路的速限就一直顯示**(它是資訊,不是警告)。
