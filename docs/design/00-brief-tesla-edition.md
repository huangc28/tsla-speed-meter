## lead 的解讀和裁定

1. **「下方的長弧」= 舊設計速度表下面那條地平線**(`horizonX`:長弧、光帶、地面漸層)。整個拿掉。(lead 的解讀,會跟車主說。)
2. **畫面 844 × 390。只換中間**:左導航(x 62–245、y 79–260)、右欄(x 592–768)、頁尾(中線 y 345.6)從 `frames/speed-meter-icons.html` 原樣複製(`navX`、`tyreColK` / `tyreColX`、`footX` 和它們要的零件),一字不改,位置不動。右欄的車門列會和圓裡的圖示重複,這一輪不管。
3. **上排**:來源 chip 和設定齒輪不動;**時間從正中間移到左邊**(放在來源 chip 右邊;車主的圖時間也在左上),把上面正中間讓給圓。車主圖上的商標、天氣、訊號、Wi-Fi、手機電量**都不畫**。音樂卡不畫。
4. **圓的大小(固定)**:lead 算過能放的最大範圍:上到 y ≈ 16、下到 y ≈ 328(離頁尾的字 ≥ 8)、左右離導航卡和右欄 ≥ 10。**目標圓心 (422, 172)、半徑 156**(車主的圖約 144)。可以在 152–160 之間調,定了就**所有畫面同一個圓、同一個位置**:一位數、兩位數、三位數、P 的 0、沒有車速的「—」都一樣,數字大小也都一樣。圓環的光暈不能碰到兩邊的卡和頁尾。
5. **數字**:字高不小於車主圖上的 72.8,字重、圓角感照圖量(疊圖比對,挑最接近的字型;app 之後用 SF Pro,所以也請比一個 SF Pro / SF Pro Rounded 的候選,報偏差)。用等寬數字,位置不隨位數左右跳。**三位數用最寬的測**(188、200、248 都要過)。
6. **圖示只留四個:前車廂、後車廂、車門、胎壓。四個格位永遠都畫**(照車主的圖:關著 / 正常 = 灰色,開著 = 紅,胎壓低 = 琥珀)。這和第二十二輪「關著不畫」相反,以車主的圖為準。圓底(深色圓 + 細邊)照圖畫。
7. **分佈,主方案「四角」**:前車廂左上、後車廂右上、車門左下、胎壓右下;左右對稱,上下兩排對數字的中線盡量對稱;9 點鐘、3 點鐘**空著**(讓三位數有地方)。角度從圖上的 ±56° / ±125° 出發去解,要過下面的淨空。前 / 後車廂留在車主圖上的位置附近,車門和胎壓下移到原本駐車、車道的格位。
8. **備案只畫一個「下弧」**:四個圖示沿下半圓等距排一排(左到右:前車廂、車門、後車廂、胎壓),最上面兩個不高過數字墨跡的底。只畫 3 張(下面狀態 2、3、7)。不要再多想第三種。
9. **淨空**(1 倍,量墨跡):圓底邊到數字墨跡 ≥ 9(用 188 / 200 / 248 量);到 `P R N D`、`km/h` ≥ 8;到圓環刻度 ≥ 6;兩個圓底之間 ≥ 8。放不下時**先動圖示位置,再不行才回報**;不要縮數字、不要動兩邊、不要讓圓變大變小。
10. **圓環**:細線、刻度、上方偏藍白、右邊琥珀、左下紅的那幾段光,照圖量了畫。**固定不動**,不跟著車速變(圖上看不出它代表什麼)。圓環上的紅和琥珀會不會和「開著 = 紅、警告 = 琥珀」搞混,留給 safety 判斷,先照圖畫。
11. **圖示**:照 `crop-*@6x.png` 量了重畫成 SVG 線條(不貼像素、不用 SF Symbols),做疊圖檢查報偏差,做法同第二十二輪(`handoff-visual-speed-meter.md` §4)。顏色取**線條像素的中位數**(不要取最亮或最飽和的一點),儀表圖為準。
12. **圖上開和關只差顏色**(前 / 後車廂的圖示關著也畫著掀起的蓋子),而且**前車廂和後車廂的圖示幾乎一樣**,只靠左右位置分。**畫面先照圖畫**。另外在「圖示對照」那一段各放一個候選修法給車主看(不放進畫面):① 關著的版本(蓋子放下);② 前車廂把蓋子畫在車頭那一側,和後車廂左右相反。
13. **圖上沒畫的狀態**照現有規矩畫,各一張,畫面外標「車主的圖上沒有,照現有規矩」:沒有有效車速 = 數字位置畫「—」(不是 0);車門狀態不明 = 同一個形狀的灰色短線段虛線(L87,第二十二輪 3b 的畫法)。不要發明新的畫法。
14. **停車**:檔位亮 P、數字 0,其他和開車一樣(圓、位置都不動)。不畫白車。
15. impeccable:動手前讀 `~/.claude/skills/impeccable/reference/craft-floor.md`。它的禁忌和車主的圖衝突時,**車主的圖贏**,把衝突列在報告裡。不要跑 impeccable 的選方向流程(車主已經定了方向)。種子規範在 `DESIGN-atelier-tesla-edition.md`(lead 寫的),畫完後 lead 會照你量到的值補數字。

# 第二十四輪(2026-11-13):車主選定,主畫面改用「下弧」+ 安全建議版(L102)

## 車主的決定

1. 安全建議版四點**全部採用**。
2. 數字字型用 **Hanken Grotesk 500**(授權 SIL OFL 1.1,lead 查過;可以包進 app)。
3. 「下方的長弧」= 舊設計的地平線,解讀對,維持拿掉。
4. **圖示排列比較滿意備案「下弧」** → 下弧變成主畫面。
5. 頁尾的「總里程」換成 **ODO**。

## lead 裁定

1. **主畫面 = 下弧的格位 + 建議版 + Hanken**。格位照現在的 `LOWARC` 不動:前車廂 −117°、車門 −159°、後車廂 +159°、胎壓 +117°(順序就是車主看到、說滿意的那個,不要改)。十一個狀態全畫(同一份 `STATES`)。圖檔 `main-01…11`(1 倍和 `@2x`)。
2. **不能動的**:圓(圓心 (422, 172)、半徑 156)、刻度、`P R N D`、數字的大小和位置、`km/h`、圓底大小、左導航、右欄、頁尾其他東西。
3. **未知**:關著的形狀畫虛線(現在建議版的做法)。虛線在關著的形狀上沒量過:1 倍要有 ≥ 2 px 的空,平頭。
4. **狀態 9**:「—」和「車速暫不可用」位置照舊;確認不碰下排圓底。
5. **ODO**:只把「總里程」那三個字換成 `ODO`。數字 `48,213 km` 右緣對齊 769 不動,標籤和數字的間距照舊(8);拉丁字的樣式跟頁尾現有的拉丁字一致,不比數字搶眼;無障礙標籤仍讀「總里程 48,213 公里」。
6. **淨空全掃**:下弧之前只實量了 188 / 200 / 248,加一個估算(10.1)。上一輪四角就是這樣漏掉尾數 7 / 5 / 4。這次 **0 到 250 每個數字**都量四個圓底到數字墨跡的最短距離(門檻 9),另量圓底到 `km/h`、到「車速暫不可用」(門檻 8)、到刻度(6)、圓底彼此(8)。不過的話:**只沿軌道移圓底**(左右對稱、四個盡量等距),不動圓、不縮數字,把移了多少報給 lead。
7. **候選一組(兩張,狀態 1 和 7)**:前後車廂換到外側成對 = 前車廂 −117°、車門 −159°、胎壓 +159°、後車廂 +117°。圖檔 `alt-01`、`alt-07`。給 ux、safety 判斷「關著的前後車廂長得一樣,只靠位置分」夠不夠用;**先不放進頁面**,lead 看審查結果再決定。
8. **頁面**(同一個檔 `frames/atelier-tesla-edition.html`,網址不變):標題 → 「最新 2026-11-13」→ 說明(車主選了什麼,白話)→ **主畫面十一個狀態** → 圖示對照(車主的圖 vs 現在用的形狀)→ 和車主的圖對照(右邊換成主畫面的狀態 2,不一樣的地方重寫)→ 一個預設收起來的 `<details>`「未選(保留參考)」:四角排列十一個狀態(照圖)、照圖和建議版的並排、SF Pro 字型比較。舊圖檔不刪。390 寬不能橫向捲。
