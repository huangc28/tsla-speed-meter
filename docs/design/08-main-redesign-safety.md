## 第十二輪審查清單

只列新增或改寫項目；其餘沿用 `03-safety-review.md` 的 D／V／A／F／C、O01–O08 及後續裁定。以下空格留給階段 3，勾選需附圖檔或驗證證據。L70 更新舊 F07、C04／C05 的門況與導航摘要範圍，其餘延期項不因此開放。操作與配色的未定部分先採以下安全建議，交 lead 裁定。

- [ ] **M12-01** 加入左右面板、上方列及環上圖示後，車速仍是唯一最大元素，不低於現行字高與 L39／R7-01–02 下限。面板換頁、檔位出現／消失、來源切換及 drive↔parked，車速中心位移均為 0 px。依 03 V01／V06、O02 最新修訂及本輪 brief「安全」。
- [ ] **M12-02** 圓環與圖示不侵入數字淨空，三位數及所有速度位置均驗證；保留筆畫旁 9 px 的最不利背景對比檢查。844／667、繁中／英文、大字、日夜與雙向橫式放不下時，先減少側欄資訊，不縮整個儀表。沿 03 V02／V03、O03／O08、R7-01–02。
- [ ] **M12-03** 每個方向明訂面板預設、上下滑順序及操作閘門。本輪建議行駛中禁止滑動、點擊換頁與音樂操作，設定／主題／字級入口同樣受限；停車後才手動選面板。沿 L6 的「已知停車」條件，不能僅以 P、GPS 0 或無資料解鎖；移動／資格失效即中止操作，不要求確認。延伸 03 D01–D03、C09。
- [ ] **M12-04** 行駛面板不定時輪播、不自動捲動歌名、不因歌曲／導航資料更新整片滑入。進入行駛版至多切到固定預設一次，之後只原位更新欄位；不因 P／來源抖動反覆換頁。減少動態時取消轉場，停車後也不自動恢復未完成手勢。延伸 03 D05、A04，見 E1。
- [ ] **M12-05** 環上每個狀態均列「開啟／關閉／未知／過期」對照，靠圖形或短文字區分，灰階仍可辨識；不能把未知與確知關閉都畫成同一個空白。必要圖示對背景 ≥3:1，必要小字 ≥4.5:1，夜間重驗；讀屏名稱包含部位與狀態。延伸 03 A01／A05、F02，見 E2–E4。
- [ ] **M12-06** 後車廂開啟、自訂門檻觸發、測速提醒、資料失效同時發生時，有固定位置與顯示優先序，不互蓋、不輪播未解除狀態、不要求點圖示才能知道意思。門況是「車輛回報狀態」，不承諾即時告警或「沒亮就安全」；不畫方向燈、盲點或 AP/FSD。改寫 03 F07、C05，依 L70 與本輪 brief「資料」。
- [ ] **M12-07** GPS 備援整張畫面撤下車輛檔位、電量／續航、胎壓、門／窗／車廂、歌曲、車上導航及總里程，不保留淡化舊值。側欄只可放已驗證的 GPS 衍生行程，明示「由手機 GPS 計算／Calculated from phone GPS」；不能混入車輛耗電。速度來源固定可見，兩來源皆失效用 `—`。收緊 03 F03／F04、C01，依本輪交付的 GPS 畫面要求。
- [ ] **M12-08** BLE 恢復後各欄分別驗新鮮度，不一次恢復全部快取；`P R N D` 仍只在檔位新鮮、有效且無移動矛盾時整排顯示。未配對、P 或車況有效都不能替未知速度填 0；圓環進度與速度同步失效。延伸 03 F01／F02、R7-03–07。
- [ ] **M12-09** 門檻明寫「自訂門檻 110 km/h／Custom threshold 110 km/h」，觸發語意為「超過自訂門檻／Above custom threshold」。不單寫「超速」「限速」，不畫道路速限牌或相機來代表它。本輪建議用中性圖示與形狀變化，車速不套用道路超速的琥珀／紅色；L53 測速卡用字例外不延伸至此。改寫 03 F05／F06、C06，依 L70。
- [ ] **M12-10** 自訂門檻只有有效新鮮車速才比較；單位換算、顯示取整、等於／超過、解除及來源切換規則可重播核對。失效立即撤除觸發態，沒有提示不代表符合法定速限；不靠閃爍、發光或聲響吸引注意。延伸 03 F01／F03、D05。
- [ ] **M12-11** 行駛歌曲只保留靜態歌名／歌手，長字截斷且不捲動。歌詞與地圖至少受停車閘門限制；本輪資料沒有歌詞，範圍也不做手機地圖，故兩者不畫成可用功能。導航只列車上目的地、剩餘時間／距離、明標的「預估抵達電量／Estimated arrival charge」；無路線或過期為空狀態，不加轉彎箭頭。改寫 03 C04，依本輪 brief「資料」。
- [ ] **M12-12** 停車面板換到胎壓時，保留 psi、逐輪缺值／舊值、共用時間行與首次說明卡；換頁不重設量測年齡，也不把歷史值當即時警示。首次說明在胎壓首次可見時同時可見，不藏到另一頁。完整胎壓與行程明細先沿停車限定；行駛摘要若需擴張，須另列理由。延伸 03 F08、R7-14–18、R7-20。
- [ ] **M12-13** 上方列逐項說明行駛用途與省略順序。本輪建議行駛只留時間、車速來源／失效、必要連線狀態；天氣、車內溫度、手機電量等非必要項移至停車摘要，音量／夜間／設定及浮動按鈕不形成行車操作列。重要失效文字不得被擠成不明小圖示，也不因面板而移位。延伸 03 D01、F04。
- [ ] **M12-14** 停車換頁提供有名稱的按鈕或頁籤，不能只靠上下滑手勢；讀屏不可繞過行車操作限制，換頁不搶車速焦點。階段 3 每方向至少核對 BLE 行駛／GPS 行駛／P 停車三張，以及未知、同時警示、大字與夜間補圖；動畫、瞥視與實機可讀性另外驗，不能以 PNG 勾選通過。沿 03 A02–A05、D04、T01–T04。

## 階段 3 審查

### 重點結論

- 第十二輪階段 3，2026-10-25，safety／Codex。九張皆逐張看過 844 × 390 原尺寸；可供挑方向，尚未完成上車使用驗收。新增 **0 P0／8 P1／1 P2**，其中 S12-07 是驗證缺口，不是已確認的實作故障。
- 車速大小、位置與目前供圖的筆畫通過；後車廂和自訂門檻圖示雖非色彩單獨傳意，實際尺寸仍不足以一眼讀出完整意思。GPS 來源文案應改回既定詞彙。
- GPS 計算註記 12 px、停車換卡按鈕字 14 px 未達各自文字角色的規格；A／B 停車用電與 GPS 註記須分組。不是所有 12 px 都違規，單位及胎壓時間行另有明訂的 12 px。
- visual Q2：有誤讀風險，須改；Q3：同意俯視方向，但車門開啟態未有原尺寸完整供圖，不能判辨識通過。07 Q11：有條件同意導航開始時換一次，但須明訂為 M12-04 的例外。
- 安全排名 **B ＞ C ＞ A**；B 行駛時沒有側面板，駕駛需要掃視的區域最少。

### 範圍、方法與判定界線

- 輸入為 `frames/main-redesign.html` 及 `frames/main-redesign/` 下九張 PNG。PNG 均為 1688 × 780，縮至 844 × 390 逐張檢視；另做灰階核對。下文尺寸都是邏輯 px／pt，未把 2× 圖當大字。粉紅 SafeArea 線與註字是設計註解，不列產品內容。

| Q11 的安全優先與重設 | 「到 P 前不再換」限制內容選擇，**不能阻止資料失效撤除**：GPS 備援仍須撤車上導航、車況；無效欄位立刻空狀態，不能為維持卡片保留舊值。測速提醒暫借同位置是 07 §2.4 既有例外，結束回原卡、不重新選。只有新鮮有效、無移動矛盾的 P 停車週期才能重設導航例外；P 抖動／過期、GPS 0 不重設。初始導航、晚開始、取消重設、斷線恢復與假 P 均須重播。這是供 lead 裁定的建議，不宣稱 L72 已核准。 |
| visual Q1，C 卡片空白，補充 | **安全上可保留空白，建議本輪維持固定框。** 空白不是安全缺陷；不必為填滿卡片加資訊。若 lead 改為依內容高度，須仍固定左上錨點、車速與來源 0 位移，不隨每次數字／長標題更新反覆伸縮，停車／行駛變化再驗。 |

### 選定方向後的最低驗證組

- **狀態圖**：前／後車廂、車門各自開／關／未知／過期；「後車廂已知開＋車門未知」；後車廂＋自訂門檻＋測速提醒並發、再加部分車況過期；GPS 備援全撤車況；兩來源皆失效用 `—`＋原因、虛線軌道且無填色／針／檔位／門檻觸發；新鮮 P 但速度未知不能補 0。L71 不要求 GPS 留虛線車。
- **排版圖**：選定方向的 844／667、繁中／英文、km/h／mph、三位數 147、長目的地／歌名、大字、高對比與最暗夜間。量 9 px 最亮鄰域、最細筆畫與圖示／▲／弧端距離；C 的全圈帶與 A 門檻刻痕都不能侵入數字淨空。先減次要資訊，不縮主速度。
- **停車／胎壓**：首次胎壓說明與換卡提示同時出現；說明在卡片外、首次同屏可見，未按下次再顯示。驗 165 寬大字清單退路、逐輪缺值／舊值／時間未知／不支援，共用時間取最舊且不隨換卡重設；點標題與上下滑都能用，實際點擊區 ≥44 pt、不重疊齒輪。
- **重播與無障礙**：新鮮 P＋任一有效移動證據、P 過期、GPS 0／未知、滑動途中起步／失效、延遲回呼、BLE 各欄不同時間恢復、來源反覆切換、Q11 例外額度、門檻取整與解除。VoiceOver 不得繞過停車閘門，不強制播每次車速；減少動態取消非必要轉場，L62 指針動畫不能延後真實數字或失效撤除。
- **使用情境**：受控測試以實際支架視距核讀速 0.3 秒目標與次要任務 2／12 秒目標；原尺寸無圖例辨前／後車廂、自訂門檻、車門，另驗強光、夜間、偏光鏡和左右橫式。這是專案驗證，非 NHTSA 認證。[E1] 手機固定支架不構成任意操作的安全或合法保證。[E5]
