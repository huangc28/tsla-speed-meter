## 重點結論

1. 查了 5 個參考:Dashla、DriveCluster、Tesla 中控的車況區、Polestar 2、BMW iDrive 8。共通做法:中間只放車速;旁邊的資訊行駛中少、停車時多;換內容用固定按鍵或停車時操作,行駛中不在螢幕上滑來滑去。
2. 三個方向:**A「雙翼」**(最像 Dashla:細圓環 + 左右兩個面板 + 上方時間;停車時選,行駛中鎖住);**B「靜行」**(保留 C 扇形 + 下半狀態弧;行駛中沒有面板,P 檔才展開兩側);**C「單卡」**(C 的質感做成 270° 圓環;右邊一張卡,開車時依情境自動選一次)。
3. 三個都守:車速數字大小和位置不變、量表區 300 × 300、`P R N D` 和 ▲ 的位置、左下電量 / 續航、來源標示不被蓋;面板只在停車畫面能換(點標題或滑),行駛中的內容進入行駛時定一次,只有「開車後才開始導航」可以自動換一次(L73)。
4. 環上固定 4 格:前車廂、後車廂、車門、超過自訂門檻。亮起時量表正下方加一行短字(例如「後車廂開著」);車子三格逐格有開、關、未知,未知畫虛線外框;沒連上車時整組不畫(L71);自訂門檻用中性色,不是 ▲,也不是道路速限。
5. 安全上 B > C > A(08 階段 3 同樣排序),最像 Dashla 的是 A。ux 建議 C:行駛中只多一張卡、不用碰,量表也變圓。A、C 改了量表形狀(L49),老闆挑方向時一起重挑量表(L72)。

**短字列**(L73):

- 和圖示同時出現、同時消失,只改透明度 ≤200 ms;字出現時車速、量表都不動。
- 不縮車速,也不用點開才看得到(L73)。大字放不下時見 §7 Q14。

**自訂門檻那一格**(L73 S12-08、08 M12-09、M12-10):

- 設定裡打開並設一個數字(例如 110)才有。打開後,錶上在 110 的位置畫一條固定細刻痕(`text.secondary`,和量表的刻度不同長度),關掉才消失。
- **亮**:畫面上顯示的整數車速**大於** 110(等於不算),用目前顯示的單位比。
- **熄**:顯示車速**小於或等於** 110 就立刻熄,不拖延。沒有有效車速(數字是「—」)時也立刻熄。
- **熄後 3 秒內不再亮**:避免在 110 上下一直閃;3 秒後如果顯示車速還是大於 110,才再亮。
- 來源切換時用新來源的顯示值繼續比;換單位時門檻跟著換算,取整到 1;只看顯示的數字,不看指針滑動途中的位置(L62)。
- 亮時:圖形 + 短字「超過 110（自訂）」;車速數字不變色、不閃、不發聲。指針 / 車速弧越過刻痕,形狀上也看得出來。
- 文字叫「自訂門檻」或「(自訂)」,不寫「超速」「限速」(M12-09)。

### 2.3 面板共用規則

**面板內容(卡)**

| 卡 | 內容 | 行駛中可以出現? | 來源 |
|---|---|---|---|
| 行程 | 見下面「行程卡的兩組」 | 可以(只有 GPS 那組的本趟、行駛時間) | GPS 那組:本機計算(GPS 車速、手機時鐘);電量變化:車輛藍牙電量起訖差 |
| 車上導航 | 目的地(1 行)、「18 分 ・ 12 km」、「預估抵達電量 64%」 | 可以 | 車輛藍牙(09 D13) |
| 正在播放 | 歌名(1 行)、歌手(1 行);沒有封面、沒有歌詞 | 可以 | 車輛藍牙(09 D26) |
| 胎壓 | 現行胎壓圖(psi、共用時間行) | **不行**(L34) | 車輛藍牙 |
| 車況 | 總里程、車外 / 車內溫度、車窗 | 不行(09 D20 總里程只適合停車) | 車輛藍牙 |

**行程卡的兩組**(L73 S12-05):

| 組 | 停車 | 行駛中 | 什麼時候不畫 |
|---|---|---|---|
| GPS 那組 | 本趟、平均、最高、行駛時間;下面一行「距離和車速由手機 GPS 計算」 | 本趟、行駛時間;下面同一行註記 | 沒有 GPS 時數值「—」 |
| (一條分隔線) | — | — | 下一組不畫時也不畫 |
| 本趟電量變化 | 「本趟電量變化 −4%」;下面一行「依車輛藍牙電量計算」 | 不放 | 只用 GPS、或這趟開始時沒有藍牙電量(起點缺值)時,整組不顯示 |

- 註記是說明小字,≥13 px(L73 S12-03)。停車時面板放不下就在面板內捲動(L24)。
- 電量變化是「起點和現在的電量 % 相減」,用了是負號(−4%),回充變多是正號;不是 kWh,也不是精確耗能。
- C 的左欄沿用現行的 3 列(本趟、平均、最高)+ 新註記,沒有電量變化那組(見 §3.3)。

**怎麼換卡(只在停車畫面)**

- **條件和現在進 S06 一樣**:自動(藍牙 2 筆不同、依序的新鮮 P)或手動(只有 GPS,S07 確認過)。**不是**「檔位 = P 就能換」:新鮮 P 但有效車速 ≥5 km/h 本來就不算停車(R7-03)。06 C09:這只是切版面的保守門檻,不代表可以分心操作。
- **兩種換法**(08 M12-14,不能只靠手勢):
  - 點標題:停車時標題變成按鈕「胎壓 ⌄」,字 ≥16 px(L73 S12-03),點擊區 ≥44 pt,往上下延伸,不跟齒輪重疊;點了在面板上蓋一個卡名清單(每列 ≥44 高,字 ≥16 px,目前那張前面打勾,不只靠顏色),選一張就關。
  - 上下滑:一次換一張,停在整張上;輕震動。
- 標題列右端有直排小點(4 px、間隔 3,目前那張實心、其他空心),只在停車時有。
- 讀屏:標題唸「胎壓，第 1 張，共 2 張，按鈕」;提供「下一張 / 上一張」動作。這些動作和按鈕只在停車畫面存在,讀屏不能繞過(M12-14)。
- 停車時選的那張會記住,下次停車回到它。
- **離開停車畫面**(車開始動、資格失效):正在進行的滑動或打開的清單立刻取消,不要求確認,之後也不自動接著做(M12-03、M12-04);面板在 300 ms 內(只改透明度,減少動態時 0 ms)換成行駛中的內容。
- 第一次在停車畫面看到可以換的面板時,出現一次性提示「停車時點標題或上下滑動，可以換內容。」+「知道了」。
- **一次性提示放哪裡**(胎壓說明和換卡提示):釘在左側面板**卡的上面**,不屬於任何一張卡;左邊換卡時提示留著不動,按「知道了」才消失。兩個都有時胎壓說明排第一,而且胎壓第一次出現的同一個畫面就要看得到、不用捲動(R7-16、M12-12)。提示在的時候,下面的卡往下排、可以捲動。

**行駛中**

- 進入行駛時,每塊面板**選一次**內容(規則看各方向),之後只原地更新數值(分鐘數、歌名);不輪播、不滑入(08 M12-04)。
- **導航的窄例外**(L73 Q11,照原文):進入行駛時,如果卡片不是導航,這一趟第一次收到新鮮、有效的車上導航時,可以自動換成導航一次,用 0.2 秒以內的淡入淡出(減少動態時直接換)。
  - 之後到 P 檔前都不再換。取消導航、改目的地、重新連上藍牙,都不會重新給一次機會。
  - 只有一次有效的 P 檔停車,才重新給一次機會(自動進停車畫面的那種 P:2 筆不同、依序的新鮮 P,沒有移動矛盾;P 抖動、P 過期、GPS 0 都不算)。
  - 資料失效時照樣撤下內容,不因為要「不換卡」而留著舊值。
  - 用在 A 的右側面板、C 的右卡;進入行駛時已經是導航就用不到這個例外。
- 選到的卡資料沒了:導航結束、播放停止 → 原位換成一行空狀態「車上沒有在導航」「車上沒有在播放」,不自己換到別張(上面的窄例外除外)。
- **資料失效**(藍牙過期、斷線,改用 GPS):要車子資料的卡立刻撤掉內容,只留標題,不寫「—」,也不寫「車上沒有在導航」(那句表示「確定沒有路線」);卡不換。藍牙恢復、資料重新新鮮時,內容在原位回來,不算換卡。
- 測速提醒照 §2.4 暫時借用位置,結束後回到原本那張。
- 碰面板沒有反應、不震動、沒有小點、標題不是按鈕;不出現「停車後才能換」這類字。

**面板裡的字**

- 數值直接換,不做補間動畫、不做跑馬燈;目的地、歌名太長時用「…」截斷成 1 行(這兩個是車子給的字)。
- 說明小字 ≥13 px、按鈕字 ≥16 px;單位、胎壓單位和時間行照 DESIGN.md 的例外(12 px)(L73 S12-03)。
- 大字:行駛中每項最多 2 行,再長就截斷;不縮字、不捲動。停車時面板內可以捲動(L24)。
- 行駛中不放:地圖、歌詞、封面、按鈕、「連接車輛」這類佔位、設定。
- 同一張卡不會同時出現在左右兩邊。

**只有 GPS**(08 M12-07、L71)

- 行駛中:面板只放行程的 GPS 那組(帶「距離和車速由手機 GPS 計算」);要車子資料的卡(導航、播放、胎壓、車況)不出現,也不畫「—」或佔位;左下角留空(01 §7.4);沒有本趟電量變化;環上車況整組不畫。這是指「進入行駛時就只有 GPS」;開到一半才失效照上面「資料失效」。
- 停車(手動 parked,或配對過但沒連上):要車子資料的卡不放進可選清單;右側面板只放一行「尚無車輛資料」,沒配對過的再加現行的「連接車輛」按鈕(08 R12-05、01 §6.2)。
