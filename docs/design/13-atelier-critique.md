## 重點結論

Status: 完成

- 最影響「像不像」的是**車的光影**,不是外形。外形逐段寬度和參考圖只差 ≤ 2 px(事實),但參考圖葉子板有亮脊、引擎蓋中間較暗、玻璃左側有反光、邊緣沒有亮外框;我們整台平亮,外圈一條淺灰線,零件(頭燈、尾燈、尾翼線、門縫)像貼上去的。修法見 §大 1–2。
- ① 弧「貼數字」是**相對**的:以 px 算,己離數字不比參考圖近(三位數 18.6 vs 參考圖等比 19.0);以數字高算才近(0.17 h vs 0.30 h)。參考圖比例要 r ≈ 211,放不下。可行的是 **r 162 → 170、速度表整組 +7.5**,三位數間距到 27.6(0.25 h)。弧心往下移會縮短弧,不建議(未選)。
- ② 速度表往右是被 SafeArea 逼的,沒問題;**車只移 25 太少**,弧到車只剩 38(參考圖 99),速度表和車黏成一團。建議**車 cx 472 → 500**,和速度表一起移約 +53,兩段空隙 50.5 / 65。
- 開著的狀態:大片平塗紅把銀色車身變成塑膠玩具,後車廂一條直線切過玻璃,掀蓋畫在車外像紅括號;右欄開著用實心圖示、關著用線條圖示,兩套不一致。沒資料的狀態不算壞質感,只有 0.38 的灰車像「灰色車漆」、「—」像一條灰色長條。
- 庚的速度表比例**真的像了**:數字高、弧直徑 ÷ 數字高、弧心位置、km/h 和 P R N D 間距都在 ±1–2 px 內;剩下的差在位置(右 25、下 8)和共用的車、導航、圖示。
