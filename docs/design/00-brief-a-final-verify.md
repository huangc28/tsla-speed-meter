## 階段

### 階段 1(visual):補畫面

在 `main-redesign-a2.html` 加新畫面,①–⑥ 不改。新畫面的 ID 用 `A-v-*`,標題寫 ⑦ 起。每張都要有預期內容,讓頁面自查能檢查。

1. **狀態**(844、繁中、白天、預設字級):
   - 前車廂 + 後車廂 + 車門都開著;
   - 部分車況過期(照 07 / L71 的規則;沒寫清楚就寫進「待 lead 裁定」,先用最合理的畫);
   - 後車廂 + 自訂門檻 + 測速提醒同時出現,再加部分車況過期;
   - 兩個來源都失效:`—` + 原因,虛線圓環,沒有檔位、沒有門檻;
   - 新鮮 P 但速度未知(「P 檔」+ 原因,不能補 0);
   - 來源標示的其他三種,都畫成圖示版(L81):
     - 從沒配對過的「● GPS」;
     - 「◌ 等待車輛…」;
     - 「▲ 車速暫不可用」。
2. **排版**:
   - 667 × 375 的 ①;
   - 英文 ①;
   - mph ①;
   - 三位數 147 + 很長的目的地(例如「臺大醫院急診部」)和很長的歌名(右邊「正在播放」);
   - 大字 ① 和大字 ③;
   - 高對比 ①;
   - 最暗夜間 ③。
3. **停車和胎壓**:
   - 首次胎壓說明和換卡提示同時出現;
   - 165 寬大字的清單退路;
   - 胎壓各種狀態:逐輪缺值、舊值、時間未知、不支援;
   - 停車右卡的其他內容:車況、車上導航、正在播放。

做完的標準:

- 頁面自查在 1280 / 1440 / 390 三種寬度都是 0 個問題;新加的檢查也要過。
