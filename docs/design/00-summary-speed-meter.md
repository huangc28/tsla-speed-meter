# 第十六輪總結:速度表不要像 Dashla(2026-11-07)

## 結論

- 車主覺得現在的速度表「完全抄 Dashla」。這一輪只換中間的速度表(車主選的範圍),上排和左右面板不動。
- A 像 Dashla 的是**結構**:細圓環 + 深色圓盤框成一塊圓牌,紅色車況燈放在圓牌裡。只換顏色沒用(`10 §1`)。
- 三個新方向都不用圓環:
  - **乙「橫尺」**:數字在上,一條橫向速度尺在下,車況燈一列放最上面;
  - **丙「直軌」**:數字靠右,右邊一條直立速度軌,左邊直排檔位和車況燈;
  - **丁「大字」**:只有更大的數字(184),超過門檻時四角出現括號,檔位和車況燈收到下方托盤。
- 車主看過後要再看一個圓的(L93):**戊「刻度扇」**,上半圈有刻度的細弧、下半開口、沒有圓盤,車況燈和檔位在弧外下方的托盤(`10 §4.4`)。
- 車主 2026-11-08 寫了 `DESIGN_v2.md`(「ATELIER — Tesla Edition」,整個畫面的方向,參考圖 `docs/atelier-reference.png`),要先做成 HTML 變體看:**己「ATELIER」**加進比較頁(L94),整個畫面照 DESIGN_v2 畫、只共用上排;導航橫條照車子給得出的資料(車子藍牙沒有下一個路口);safety 還沒審己。
- 安全審查 0 P0 / 2 P1 / 2 P2(戊加 1 個 P2),暫排 丁 > 乙 > 甲 > 戊 > 丙(`11 §7`)。P1 一條是檔位顏色的字面衝突(L91 裁定為例外),一條是選定後才驗的缺口(S16-02)。
- 比較頁:`frames/prototype-speed-meter.html`,六個版本(甲–己)× 車速 0 / 8 / 72 / 128 / — × GPS 備援 / 車門 / 三格都開 / 超過門檻。
