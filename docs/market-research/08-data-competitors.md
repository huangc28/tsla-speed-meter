## 重點結論

1. **資料來源決定功能邊界，原生 `Tesla BLE` schema 涵蓋 12 項免拆車資料點（均待實車解密驗證）**：現行競品分為「純 GPS」、「原生 `Tesla BLE`（vehicle-command / CarServer）」、「雲端 `Fleet API / Telemetry`」與「`CAN 匯流排`硬體」四層；對照 `09-data-feasibility.md` 與競品實作，原生 `Tesla BLE` schema 包含 **車速(`D01`)、檔位(`D04`)、電量(`D09`)、續航(`D10`)、粗略功率(`D11`)、原車導航路線摘要(`D13`)、四輪胎壓(`D15`)、車外溫(`D18`)、總里程(`D20`)、充電狀態(`D21`)、車門/廂/窗(`D22`/部分`D16`)、媒體文字(`D26`，無封面)、車內溫/空調(`D27`)、海拔/航向(`X03`)** `[事實][09]`。
2. **「方向燈(`D05`)、盲點(`D06`)、定速(`D07`)、AP/FSD(`D08`)、大燈(`D17`)、馬達/電池溫度(`D28`)」在零硬體下實務上做不到即時顯示**：原生 BLE 無上述欄位；雖雲端 `Fleet Telemetry` 有 `D05`/`D07`/`D17`/`D28` 部分欄位，但延遲與斷線補送不適合當即時安全提示，因此 DriveCluster、Dashla 明寫需選配外接 **TITA CAN 發射器（US$79.98）** 擴充 `[事實][09]`；TPlayer 的方向燈卡片沒有標明來源，它另有雲端 Fleet API 模式 `[事實][11]`。
3. **基本盤是「車速 + 檔位 + 電量/續航」；軟體供給差異在「測速照相 + 自建導航/原車導航摘要 + 胎壓」**：幾乎所有連車產品皆提供 `D01`、`D04`、`D09`、`D10` `[事實]`；在免硬體 App 供給面，台灣競品（Dashla）免費內建固定測速(`D03`)與自建導航(`D12`)，美國競品（DriveCluster）免費提供原生 BLE 胎壓(`D15`)、充電(`D21`)與原車導航摘要(`D13`) `[事實]`。
4. **硬體儀表評論顯示車主反感「假 3D 車道動畫、音訊衝突的 CarPlay」，而抱怨缺少「原車導航同步與轉彎盲點提示」**：Amazon、Reddit 與台灣社群評論中，平價硬體儀表的固定假 3D 車模(`D23`)與搶音源的 CarPlay(`X04`)常被批評沒用；車主較常抱怨缺少的是**與 Tesla 原車導航同步(`D12`)、打方向燈時的盲點提示/影像(`D06`/`D25`)，以及不擋冷氣、OTA 後數據準確的穩定度** `[事實][07]`。
5. **產品定位建議**：依 `10-data-priorities.md`，零硬體版的核心價值在於**「把基準項目（`D01` 車速、`D04` 檔位、`D09`/`D10` 電量續航）做準、隧道不中斷、P 檔安全切換 parked，加上台灣免費固定測速(`D03`)與無廣告輕量體驗」**，並在文案誠實說明方向燈、盲點與下一轉彎需接線硬體故不提供 `[推論][10]`。

## 矩陣：資料點 × 產品（`D01`–`D28` 及 `X01`–`X06`，共 34 列）

### 產品範圍與欄位代號說明

本矩陣涵蓋美國與台灣市場共 **15 款代表性產品**，分為四大類：

- **A. 手機 App（7 款，美/台 App Store 與 Google Play）**
  1. **Dashla**（iOS `id6760206753`）：台灣導航榜熱門 App，支援原生 `Tesla BLE` + `GPS` + 手機自建地圖導航，可選配 TITA 硬體發射器 `[事實]`。
  2. **DriveCluster**（iOS `id6762794279`）：美國評分最高（4.8★/22 則）之原生 `Tesla BLE` 儀表 App，v3.1.0+ 支援選配 TITA 硬體發射器 `[事實]`。
  3. **特別玩家 TPlayer**（iOS `id6478885519` / Android）：中台車主常用之 `Tesla BLE` + `Fleet API` 儀表與控車 App，亦支援選配 TITA 發射器 `[事實]`。
  4. **S3XY App**（iOS `id1582684383` / Google Play）：Enhance Auto 出品，App 免費下載，但必須搭配專用 `S3XY Commander`（CAN 硬體）才能顯示車輛資料 `[事實]`。
  5. **Teslogic Dash App**（iOS `id1612735877` / Google Play）：App 免費下載，必須搭配 `Teslogic Transmitter`（CAN 硬體）才能運作 `[事實]`。
  6. **Scan My Tesla**（iOS `id1563161428` / Google Play）：工程診斷儀表 App（付費 App + 需自備 OBD/CAN 藍牙轉接頭與專用線束） `[事實]`。
  7. **通用 GPS 測速/時速 App（台灣：神盾測速照相 / 美國：Speedometer 55）**：純手機 `GPS` 方案，不連車 `[事實]`。
- **B. 副廠硬體儀表（方向盤後小螢幕，挑 Amazon、蝦皮、淘寶討論度高之 4 類代表）**
  8. **3.5"–4.6" 出風口極簡長條小螢幕**（代表型號：Veekys / Hansshow Ultra Mini 4.6" / Tesery / 淘寶蝦皮隱藏式嵌合小儀表）：嵌入空調出風口前緣之 Linux 微型螢幕 `[事實]`。
  9. **6.8"–9.6" 方向盤後大型 CarPlay 儀表螢幕**（代表型號：Hansshow F9 / F9-C、Tlyard T9/T12、Tesstudio 9"）：支援無線 CarPlay/Android Auto 及選配前保桿鏡頭之大型副廠儀表 `[事實]`。
  10. **Enhauto S3XY Dash**（9.6" 智慧觸控儀表）：Enhance Auto 旗艦硬體儀表，搭配 Gen 2 Commander `[事實]`。
  11. **TITA 智慧車載碼錶（餅 Basic / Pro / Ultra）**：磁吸圓形小碼錶，搭配 TITA 發射器 `[事實]`。
- **C. HUD 產品（Model 3/Y 專用 HUD，挑 2 款主流構型）**
  12. **Model 3/Y 專用前擋投影式 HUD**（代表型號：Vjoycar T3 / 淘寶蝦皮隱藏式出風口前擋反射 HUD）：安裝於方向盤前方或出風口、直接投射於前擋玻璃 `[事實]`。
  13. **Model 3/Y 光學結合鏡式（Combiner Glass）HUD**（代表型號：Hansshow / 淘寶專用自帶透明反射鏡片 HUD）：自帶光學反射鏡片以減輕前擋雙重鬼影 `[事實]`。
- **D. 硬體發射器（3 款 CAN 轉 Bluetooth 橋接硬體）**
  14. **TITA 數據發射器（TITA Data Transmitter）**：接原車 CAN/PING 線組，以 Bluetooth 傳送訊號供 TITA 碼錶、Dashla、DriveCluster、TPlayer 讀取 `[事實]`。
  15. **Enhauto S3XY Commander（Gen 2）**：接原車 CAN 線組，供 S3XY App、S3XY Dash、S3XY Knob/Buttons 讀取與雙向控車 `[事實]`。
  16. **Teslogic Transmitter（V2）**：接副駕或後座 CAN 線組，供 Teslogic Dash App 讀取與控車 `[事實]`。

### 標記規則說明

- `✅免費`：下載 App 後無須付費訂閱、亦無須購買任何外接硬體即可使用（可能含橫幅廣告，如 Dashla 免費版）。
- `💰付費`：需付費解鎖（含 App 內購 IAP/訂閱、或**必須購買外接 CAN 硬體/副廠螢幕/HUD 硬體**才能獲得該資料點；括號內標註條件，如 `💰付費(IAP)`、`💰付費(需TITA)`、`💰付費(硬體)`）。
- `❌沒有`：產品官方規格、介面截圖與車主實測確認不提供該資料點。
- `❓查不到`：公開商品頁、說明書與評測未明確提及是否支援。

## 基本盤 / 差異化 / 原生 BLE 缺少而需硬體之項目

### 1. 基本盤（Table Stakes：幾乎所有連車產品都必備的基準資料點）

只要宣稱是「Tesla 專用儀表或 HUD」的連車產品（無論是原生 BLE App、CAN 發射器 App、副廠硬體小螢幕或 HUD），幾乎都將以下 4 項列為基本盤 `[事實]`（在 `07-data-voice.md` 中亦歸為「基準項目：很少人主動要求，但數字不準就會被罵」`[07]`）：
- **`D01` 車速（km/h 或 mph）**：所有產品字體最大、最核心的視覺主角。
- **`D04` 檔位（P / R / N / D）**：解決起步或倒車換檔時確認檔位的需求，且 `P` 檔是切換 `parked` 模式的唯一安全依據 `[06][10]`。
- **`D09` 電量百分比（SOC %）** 與 **`D10` 續航里程**：電動車最基礎的電量指標（車主對這兩項的抱怨集中在「和車機中控顯示不一致或 OTA 後卡死」`[07]`）。

### 2. 差異化（Differentiators：決定純軟體 App 競爭定位的資料點）

在免購買硬體的純軟體 App 市場中，各產品透過以下資料點做出差異化：
- **`D03` 固定測速照相提醒（台灣市場頭號剛需，聲量 ~19 則）**：
  - 台灣固定測速桿密集，Dashla 與 TPlayer 皆在免費版內建測速提醒作為台灣車主入場券 `[事實]`；反觀美國開發的 DriveCluster 沒有測速照相(`D03`)與道路速限(`D02`) `[事實]`。
- **`D15` 四輪獨立胎壓（TPMS 數值與警告，美國聲量 9[5] 則、台灣 1 則）**：
  - DriveCluster 與 Dashla 皆在免費版利用原生 BLE 顯示四輪胎壓數值與顏色警告 `[事實]`。因 TPMS 感測器本身更新較慢，適合放在 `parked` 畫面（附上讀值年齡）並於行駛中僅保留 `tpmsHardWarning*` 觸發警示 `[09][10]`。
- **`D13` 原車導航路線摘要（目的地、ETA、剩餘距離、預估抵達電量 `activeRoute*`）**：
  - 原生 `Tesla BLE` 的 `DriveState` 內含 `activeRouteMinutesToArrival`、`activeRouteMilesToArrival` 與 `activeRouteEnergyAtArrival`，DriveCluster 與 Dashla 皆免費顯示此項，而 3.5"–4.6" 副廠 CAN 小螢幕與傳統 HUD 反而無法讀取 `[事實][09]`。
  - **注意需求與供給落差**：雖然供給面容易取得（隨 `DriveState` 一併讀取），但 `07-data-voice.md` 顯示車主主動要求的是 **`D12` 導航下一個轉彎箭頭（美國 19[12] 則、台灣 9 則，原生 BLE 拿不到）**，而對 `D13` ETA/抵達電量的需求聲量極低（僅美國 2 則舊討論 ⏳、台灣 0 則） `[事實][07][09]`。因此 `D13` 僅適合作為 `v1.x` 的低成本順帶加分項，不應當作主打賣點 `[推論][10]`。
- **`D21` 充電狀態（充電功率 kW、上限、預計完成時間）与畫面切換釐清**：
  - **查證結論（修正 `02` 與原 `08` 矛盾）**：根據 DriveCluster US/TW App Store 官方說明與截圖（`id6762794279`，2026-10-16），DriveCluster 支援在**插槍充電時（while charging）**顯示即時充電功率（kW）、充電上限與預計完成時間（見官方截圖 `iphone65-02-charging-landscape.png` 與 Live Activities 說明） `[事實]`；但在一般行駛（D/R 檔）與非充電停車（P 檔）之間，DriveCluster 採單一多面板畫面（`"What fits on one screen"`）與橫向手動切換面板（行駛資訊 / 胎壓 / 溫度），**並沒有「打入 D 檔極簡只看車速 ↔ 打入 P 檔才自動展開豐富停車面板」的依檔位自動切換** `[事實]`（依 P/D/R/Charging 自動切換多畫面為硬體競品 **Enhauto S3XY Dash** 的功能 `[事實]`）。
- **`D26` 媒體/音樂資訊（歌名、歌手、封面、歌詞）**：
  - 原生 `Tesla BLE` 僅提供歌名、歌手、專輯名稱與播放時間文字，**沒有封面與歌詞欄位** `[事實][09]`。DriveCluster 畫面上的專輯封面可能來自外部音樂服務匹配（未證實） `[推論][09]`；Dashla 則將外部抓詞之「動態歌詞與背景柔焦」列為付費 Pro 賣點，但也成為手機發燙與耗電的原因之一 `[事實][02][07]`。

### 3. 原生 BLE 缺少、零硬體實務上做不到即時顯示的項目（需依賴 CAN 硬體或外部圖資）

依 `09-data-feasibility.md` 查證，以下項目在**原生 `Tesla BLE` 協定中沒有對應欄位**；雖然部分項目在雲端 `Fleet Telemetry` 有欄位，但因延遲與斷線緩存補送不能當行駛中即時提示，故**零硬體 App 實務上做不到即時顯示，目前低延遲方案主要依賴接 `CAN 匯流排` 的硬體** `[事實][09]`：

| 分類 | 資料點 | 原生 BLE | 雲端 Fleet Telemetry | CAN 硬體（TITA / S3XY / Teslogic / 副廠螢幕） | 實務結論（對齊 `09` 與 `10`） |
|---|---|---|---|---|---|
| **A. 原生 BLE 無、雲端有欄位但不即時、即時顯示需 CAN 硬體** | `D05` 方向燈、`D07` 定速設定速度、`D16` 安全帶、`D17` 遠光燈、`D24` 跟車距離設定/FCW敏感度、`D28` 馬達/電池溫度、`X02` 煞車踏板 | ❌ 無欄位 `[事實][09]` | ⚠️ 有欄位，但 500 ms 分桶 + 間隔 + 斷線補送，不適合即時提示 `[事實][09]` | ✅ 供應商支援顯示（TITA 宣稱整體約 50 ms，逐訊號延遲待驗） `[事實][09]` | **零硬體版不做**；DriveCluster、Dashla 明寫要用戶另購 TITA 發射器（US$79.98）才顯示；TPlayer 方向燈卡片沒標來源，它也有雲端 Fleet API 模式 `[事實][09][10][11]`。 |
| **B. 原生 BLE 與公開雲端皆無即時狀態、僅 CAN 硬體廠商宣稱** | `D06` 盲點/側後方來車、`D08` AP/FSD 即時狀態與握方向盤提醒、`X01` 紅綠燈號誌提示 | ❌ 無欄位 `[事實][09]` | ❌ 無當下來車或完整即時接手欄位 `[事實][09]` | ⚠️ 硬體廠商宣稱支援（`X01` 號誌與 `D08` 完整接手語意未獲公開 SDK 證實） `[事實][09]` | **零硬體版不做**；安全警示不可用推測或未知狀態冒充 `[09][10]`。 |
| **C. 原生 BLE、雲端與 CAN 匯流排皆拿不到原車資料** | `D12` 原車導航下一轉彎、`D23` 完整 3D 周遭視覺、`D25` 原車轉彎/倒車影像、`X06` 原車後方影像常駐 | ❌ 無欄位 `[事實][09]` | ❌ 無轉彎箭頭、完整 3D 場景或影像流 `[事實][09]` | ❌ CAN 匯流排無原車轉彎指令、無 3D 視覺流、無相機影像流 `[事實][09]` | 連硬體發射器也拿不到原車資料（副廠大螢幕的 `D12` 靠手機 CarPlay、`D23` 是假固定動畫、`D25` 是另拉線外加前鏡頭） `[事實][09]`。 |

> **註：`D11` 即時功率/動能回收不屬於此類**：原生 BLE 的 `DriveState.power`（int32，kW）已可取得粗略功率（本 repo 已映射，待實車驗證正負號），並非必須接 CAN 硬體 `[事實][09]`。

## 評論中的缺漏抱怨（硬體儀表車主抱怨「少了什麼」vs.「多了沒用的東西」）

綜合 Amazon、Reddit（`r/TeslaModel3`、`r/TeslaModelY`、`r/TeslaLounge`）、台灣 PTT Car 板、DDCAR 與 YouTube 副廠儀表評測留言（對照 `07-data-voice.md` 語料），針對方向盤後方的**副廠硬體儀表（3.5"–9.6"）與專用 HUD**，車主真實抱怨如下 `[事實][07]`：

### 一、車主抱怨「少了什麼」（Missing Features）

1. **少了「與 Tesla 原車導航同步的下一個轉彎提示 (`D12`)」**：
   - **痛點詳情**：3.5"–4.6" 小螢幕與 HUD 完全沒有導航提示；而 6.8"–9.6" 大螢幕雖然有 CarPlay，但當車主使用 **Tesla 原車導航（為了超充站規劃、電池預熱與 FSD）** 時，前方副廠儀表無法同步顯示原車導航的下一個轉彎(`D12`)，或者手機自建導航路線與特斯拉車機路線不同步（Dashla 台區評論亦有 3 則抱怨路線打架），導致車主仍須看中控大螢幕 `[事實][07]`。
2. **少了「打方向燈時的原車側後盲點鏡頭畫面 (`D25`) 或清楚的盲點警示 (`D06`)」**：
   - **痛點詳情**：許多買家在 S3XY Dash 或 9 吋副廠螢幕評測留言表示，希望能直接把打方向燈時中控彈出的葉子板側鏡頭畫面(`D25`)放到正前方螢幕；但因 CAN 線組沒有視訊流，副廠螢幕無法取得原車側鏡頭影像（僅能顯示色塊燈號或另裝前保桿有線鏡頭） `[事實][07][09]`。
3. **少了「台灣本地測速照相提醒 (`D03`)」（針對 3.5"–4.6" 小螢幕、TITA 碼錶與 HUD）**：
   - **痛點詳情**：台灣車主購買極簡長條小螢幕、TITA 圓錶或專用 HUD 後，因封閉式硬體無台灣測速圖資，開車時仍得另外架手機開「神盾」或「Dashla」 `[推論]`。
4. **少了「Tesla OTA 更新後的數據準確度（`D01` / `D09` / `D10`）」**：
   - **痛點詳情**：車主在 Reddit 與 YouTube 抱怨副廠儀表出現「電量顯示 101%」、「車機 100% 但副廠顯示 87%」、或 Tesla 2024.20.1 更新後 Hansshow F68「電量卡在 100% 且續航跳到 3,000 英里 / 卡在 17%」，以及時速與中控相差 1–2 mph `[事實][07]`。

### 二、車主抱怨「多了沒用的東西」（Useless Bloat & Gimmicks）

1. **多了「不會動的假 3D 車道與周遭車輛動畫 (`D23`)」**：
   - **痛點詳情**：部分 6.8"–9" 副廠螢幕在畫面上塞入模仿舊款 Model S/X 的「車道線 + 前車視覺動畫 (`D23`)」；但因 CAN 匯流排拿不到完整 3D 周遭物件座標，畫面上的小車只是死板固定的裝飾動畫，甚至有車主明確表示周遭車輛動畫反而讓人分心（`"finding it distracting"`） `[事實][07][09]`。
2. **多了「音源衝突、延遲或畫蛇添足的 CarPlay (`X04`)」**：
   - **痛點詳情**：部分買家購買 9 吋 CarPlay 螢幕後，抱怨音訊轉接延遲、搶藍牙音源，或認為特斯拉原車網路、導航與 FSD 已夠用，外接 CarPlay 反而「畫蛇添足」 `[事實][07]`。
3. **多了「擋住冷氣出風口的硬體外框」與「大太陽下看不見的反射/HUD」**：
   - **痛點詳情**：加裝在方向盤後方的中大型硬體儀表常被抱怨阻擋冷氣直吹臉部；而投影式 HUD 或鏡面反射顯示器（含 TITA 顯示器）則在 Reddit 被車主抱怨戴偏光墨鏡看不見或白天陽光下毫無用處（`"WORTHLESS on bright days"`，`r/TeslaLounge` `1ptlwiv`） `[事實][07]`。
4. **多了「干擾視線的次要雜訊（時間、外溫、假轉速錶）」**：
   - **痛點詳情**：極簡派車主在評論與留言中反問為何要在正前方塞入時間(`D14`)、車外溫度(`D18`)或假 RPM 轉速錶(`D11`/`D28`)，認為正前方只需要大字車速與少數關鍵提示 `[事實][07]`。

## 美國與台灣差異（競品生態與需求/供給對比）

## 假設

1. **假設 1（原生 BLE 選填欄位的實車可得性）**：假設 DriveCluster 與 Dashla 在免硬體模式下顯示的原生 BLE 資料點（`D01`、`D04`、`D09`、`D10`、`D11`、`D13`、`D15`、`D18`、`D20`、`D21`、`D22`、`D26` 文字、`D27`），在完成本 repo 的 BLE 回應解密後，於主流 Model 3/Y 車型與韌體上可穩定讀出數值（目前本 repo 僅映射 5 項且尚未接通解密，所有 BLE 欄位皆屬「schema 有、待實車驗證」） `[假設][09][10]`。
2. **假設 2（TITA 硬體相容性僅作為 PMF 之後的選配評估）**：Dashla、DriveCluster、TPlayer 雖皆支援外接 TITA 發射器以補齊 `D05` 方向燈與 `D06` 盲點，但 TITA 的 Bluetooth 協定/SDK 開放程度與逐訊號延遲尚未獲獨立驗證 `[09]`；假設我們在 v1 階段採「誠實不做、文案寫明本版本不提供」(措辭照 `06` Part C C02,不斷言原廠政策)即可服務極簡派與測速焦慮族，無須在驗證 PMF 前投入硬體合作 `[推論][10]`。
3. **假設 3（行駛中極簡 + 停車時車況的模式分流價值）**：由於 DriveCluster 將多面板同時塞在單一畫面（`"What fits on one screen"`）而未做「D 檔極簡 ↔ P 檔展開」的依檔位自動切換，假設我們提供「依 BLE P 檔安全自動切換 parked + 行駛中『純車速 / 車速+狀態列』切換開關」，能同時滿足極簡派（約 1/4）與少數指標派（約 6 成）的需求 `[推論][07][10]`。

## 待驗證問題

1. **本 repo 原生 `Tesla BLE` E2E 解密與更新頻率實測（對齊 `09` 與 `10` spike 清單）**：完成 BLE 回應解密後，`DriveState` 在 1 Hz / 2 Hz 排程下的資料年齡 P95 是否 ≤1 秒？`ChargeState`（`D09`/`D10` 電量續航）與車機螢幕顯示誤差是否 ≤1%？`activeRoute*`（`D13`）與 `TirePressureState`（`D15`）在實車上是否回傳有效值且不拖慢 `DriveState`？
2. **DriveCluster 媒體封面（`D26`）與充電畫面（`D21`）之實機行為細節**：DriveCluster 在無網路環境下是否仍能顯示專輯封面（以驗證其封面是否確由 iTunes/Spotify 等外部 API 依歌名查詢）？在插槍充電但未排入 P 檔（或僅排入 P 檔未插槍）時，其主畫面版面是否會改變？
3. **沒有 `D05` 方向燈與 `D06` 盲點對轉換率的實際影響（對齊 `10` H14）**：在 App 內與商店頁面誠實告知「因原廠未開放手機藍牙讀取，本 App 不顯示方向燈、盲點与轉彎箭頭」後，未付費或流失用戶中以「缺少方向燈/盲點」為主因的比例是否 ≤20%？
