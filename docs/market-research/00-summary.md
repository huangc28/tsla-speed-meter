# 市場研究總結 — tsla-speed-meter

主持人(lead)整合,2026-10-17。依據 `01`–`06` 六份報告,`03` 以 2026-10-17 修訂版為準。全部是桌面研究,還沒有訪談過真實車主。

## 一句話結論

**值得做,但規模是個人副業,而且要先台灣、後美國。** 上市前必須先修好速度有效性的安全問題,並通過 BLE 實車驗證。

最痛的三群人:台灣怕被測速照相開單的車主、從有 HUD 的車換過來的人、視力吃力或年長的駕駛。見 [01](01-pain-points.md)。

## 上市前必須解決

摘自 [06 Part B 最終分類](06-risk-review.md);追加研究帶來的新項目見 06 Part C(最終分類表裡標「Part C 新增」的 10 列)。「移除該功能或手法」也算解決,但不能只加免責文字。

**P0(直接影響安全)**
1. **速度有效性與 parked 切換**。主持人已在原始碼確認以下問題:
   - `lib/src/trip/mode_controller.dart:7-9`:速度 ≤0.5 m/s 就切到 parked,≥2.0 m/s 才回 drive,預設為 parked。紅燈蠕行、塞車都會被判成停車。
   - `lib/src/speed/speed_processor.dart:41-49`:沒有速度也沒有座標的讀數會變成有效的 0(`hasValue=true`)。
   - `lib/src/speed/speed_processor.dart:38-40`:定位變差時一直沿用最後的速度,沒有過期機制。
   - `lib/src/ui/parked_screen.dart:117-124`:parked 畫面寫死「0 km/h」,不看實際速度、定位狀態和單位設定。
   - 修正方向:速度未知要顯示「—」,不能顯示 0;停車判斷不能只靠 GPS 零速,BLE 的 P 檔(而且要是新鮮資料)才是必要證據。
2. **BLE 實車驗證**:能力矩陣、資料新鮮度與失效處理、金鑰權限說明。若 BLE 不做,就撤下所有 BLE 付費宣稱。
3. **安裝與 mirror**:安裝位置要避開安全氣囊、操控和視野;mirror mode 沒驗證過就不開放道路用途。

**P1(影響上市決策、審核或責任)**
4. **台灣固定測速提醒**:要驗收誤報與漏報,說明資料限制,並如實送審。做不到就停用,並撤下相關宣傳。
5. **文案與品牌**:不用 Tesla / TSLA,不宣稱「0.3 秒」「完全合法」「零風險」,不做沒有證據的競品攻擊。
6. **付費與通路**:實測 Offer Code、恢復購買、退款。05 提到的 IAP Promo Code 已停止新建,要改掉;不綁購車推薦碼禮包,不誘導評分,不做推文衝榜。
7. **撤下免費支架 3D 列印檔(STL)**:免費不等於不用負責,沒驗證過就不提供。

## 上市計畫(前 90 天)

摘自 [05](05-gtm.md),並依 [06 Part B](06-risk-review.md) 修正。

- **順序**:兩地都先 TestFlight beta 再公開上架。台灣先上;美國在台灣 beta 期間先用 landing page 測付費意願。05 把美國上架排在 Day 76–90,這要以 04 的擴張 Gate 為前提。
- **台灣通路**:PTT、DDCAR、Mobile01、LINE 車友群、車媒和部落客(用專屬 Offer Code)、手機架品牌合作(Dashla 和 JOWUA 就是這樣起量的)。
- **美國通路**:r/TeslaLounge 和 TMC 論壇(r/TeslaModel3、r/TeslaModelY 禁止未經版主許可的自我宣傳)、Facebook 新車主社團、1 萬–10 萬訂閱的中小型 YouTuber。
- **美國的破冰點**:GPS 版免配對、開了就能用,正好避開 DriveCluster 最大的阻力(車主不信任要 VIN 和車鑰匙權限的 app)。
- **ASO**:不能用 Tesla 當關鍵字,改用功能長尾詞(台灣:測速照相、抬頭顯示器、時速表;美國:car speedometer、digital cluster)。
- **預算**:前 90 天 ≤ US$500 / NT$15,000,不投放買量廣告。

## 研究限制

- 全部是桌面研究,痛點證據來自論壇和評論。結論要找真實車主驗證,至少包括你那位 Tesla 車主朋友。
- 下載數、付費率、需求比例都是假設;Dashla 自稱的「1.7 萬用戶」沒有經過驗證。
- BLE 能不能用,還要等實車 spike(Issue #11)。
- 美國法規只查了聯邦和 CA、MN、TX,不是 50 州完整盤點。

## 建議下一步

1. 修 P0 程式問題:速度有效性、parked 判斷、parked 畫面寫死的 0。這不受市場研究結論影響,本來就該修。
2. 完成 BLE 實車 spike(Issue #11)。它決定 BLE 付費版成不成立。
3. 決定獨立品牌名稱。
4. 評估台灣固定測速提醒的實作方式和資料品質(警政署 data.gov.tw 資料集 7320)。
5. 訪談 5–10 位車主,台灣和美國都要,用來驗證 01 和 04 的假設清單。
6. 台灣 TestFlight beta。

## 追加研究:車主想在 app 上看到哪些行車資訊(2026-10-17)

依據 [07](07-data-voice.md)、[08](08-data-competitors.md)、[09](09-data-feasibility.md),由 [10](10-data-priorities.md) 整合。題目和共用資料點清單見 [00-brief-data-needs](00-brief-data-needs.md)。

**一句話:車主最想要的,正好是零硬體拿不到的。** 所以 v1 的做法是把基本項目做準,做不到的在文案裡講清楚。

| | 車主最想在眼前看到的(依 07 則數) | 零硬體拿得到嗎(依 09) |
|---|---|---|
| 美國 | 盲點、下一個路口轉彎、道路速限、AP/FSD 狀態、方向燈 | 只有速限可以(要用開放圖資),其他拿不到 |
| 台灣 | 測速照相、下一個路口轉彎、方向燈 | 測速可以(政府資料加 GPS),其他拿不到 |

- **BLE 拿得到的**:車速、檔位、功率、電量、續航、原車導航的剩餘時間和距離、胎壓、溫度、車門、充電。除了前幾項,車主幾乎只在停車時才提。
- **BLE 拿不到的**:方向燈、盲點、定速、AP/FSD。Tesla 雲端有部分欄位,但延遲太大,不能拿來做即時提示。DriveCluster、Dashla 是靠外接約 US$80 的 TITA 硬體補這幾項。
- **方向燈已獨立查證([11](11-turn-signal-ble.md))**:BLE 拿不到,信心高。Tesla 官方協定最新版(vehicle-command main `a4b43c1`,2026-09-25)三個 proto 檔都沒有燈號狀態,另有三條獨立證據(GitHub issue、解編譯的官方 app、Tesla 雲端欄位對照表)。不加裝硬體的話,只剩 Tesla 雲端這條路,但延遲是秒級,還要 Tesla 帳號和自架伺服器,不建議。實車 spike 解密成功後,可以順便傾印車子回傳的未公開欄位,低成本確認到底。
- **repo 現況**:`feature/goal-2-ble` 的 client 收到車子的加密回應後只記錄下來,還沒解密(`lib/src/ble/tesla_ble_client.dart:181-194`),讀值也還沒接到 HUD。所有 BLE 項目都是「欄位存在、待實車驗證」。

**建議(詳見 10,已經 06 Part C 審查):**
1. **drive 模式小改**:大字車速 + 只在需要時出現的提示區 + BLE 連上時才出現的小字狀態列(檔位、電量)。另外加「純車速」開關,首次啟動讓使用者選;版面和測速提醒是兩個獨立開關。v1 的提示區實際上只有台灣測速。
2. **拿不到的不做,也不假裝有**:說明文案只講「本版本不提供」,不斷言 Tesla 的政策(用 06 Part C 的措辭,不寫「原廠沒開放手機、一定要接線」)。D02 速限列為美國上架前第一個重評項目;不自建導航;TITA 相容最早 v1.x 之後,三個條件都成立才評估。
3. **BLE 付費包先講資料來源,再講停車車況**:「讀取車輛回報的車速、檔位與電量,不依賴手機 GPS 估算」。實車驗證通過前不能用;也不寫「和車上一模一樣」「隧道不中斷」「比 GPS 快」。台灣 NT$290 仍成立;美國因為 DriveCluster 免費,改成雙版本測試,兩組用同一個「付款意向」指標比較。
4. **v1 範圍小幅變更**:新增純車速開關、首次啟動選擇、「本版本不提供方向燈和盲點」的說明;parked 胎壓改成條件式 v1;原車導航摘要列 v1.x,首發不承諾。
5. **P 檔只是切換版面的條件**,不是「已安全停車」的證明(06 C09)。
6. **實車 spike 先驗三件事**:DriveState 在 1–2 Hz 下資料夠不夠新、P 檔判斷可不可靠、電量和續航跟車上一不一致。
